God of War: Ascension PC Port

Ascension-R is an unofficial, native Windows port of God of War: Ascension (PS3), made by static recompilation. The game's own code runs as x86-64 code and its graphics are drawn with Direct3D 12, with no emulator running while you play.

Download the Kit Source on GitHub

No game files are included. You need your own copy of the game and its license: the launcher builds the game's code on your PC from it. Ascension-R is still an alpha: it plays the opening of the game, but it has not been played from start to finish.

A native port, not an emulator

An emulator such as RPCS3 imitates the PS3 and runs the game's code as it goes. Ascension-R translates that code once, ahead of time: the PPU code to C++ and the SPU programs to C, compiled for x86-64 on your PC. The ps3recomp runtime stands in for the PS3's system, and the game's RSX commands are drawn with Direct3D 12. RPCS3 is used only to decrypt your copy.

Features

  • A launcher with a ready check, three presets (Smooth, Balanced, Faithful) and every setting. It finds the game's folder by itself and says when a newer release is out.
  • Picture: internal resolution from 1x to 4x or native, AMD FSR 1 and FSR 3.1 scaling, FSR 3.1 frame generation, SMAA and anisotropic filtering.
  • Display: windowed or borderless, ultrawide, VSync, a frame rate cap, and frame rate and load on screen.
  • Game patches: switch off MLAA, depth of field, motion blur, mesh trimming or dynamic shadows.
  • Cheats: damage to and from Kratos, max red orbs, infinite magic and items, infinite rage and double jumps.
  • Controls: keyboard and mouse, Xbox and other XInput pads, and through SDL3 the DualShock 4, the DualSense, Switch controllers and many others.
  • Saves with a backup before the game writes over one, and a button that makes a problem report.

Status

  • It boots, plays the cinematics and goes through the menus into the levels. The opening plays: the prison, the first fight and the gate, at about 30 frames a second in the first fight with FSR 3.1 on a laptop with a Ryzen 5 4600H and a GTX 1650 Ti.
  • Further in it has been played in parts, not from start to finish, so expect problems.
  • Windows 10 or 11, 64-bit. On Linux, one player plays it through Proton.
  • Single player only: online is not supported.

Each release's notes have the full status, the known issues and what changed: releases.

What you need

  • Windows 10 or 11, 64-bit, a CPU with AVX2 and FMA, and a GPU with Direct3D 12.
  • Your own copy of God of War: Ascension: the digital US release NPUA80918, installed in RPCS3 with its license and all of its updates from 1.04 to 1.12, in that order.
  • About 1.5 GB free on the disk while the launcher builds the game's code.

How to install

  1. Download the Kit zip from the releases page and unpack all of it into a folder of its own.
  2. Start Ascension-R.exe. It is not signed, so Windows SmartScreen may stop it the first time: More info, then Run anyway.
  3. The launcher looks for the game on every disk. If your copy still has to be decrypted, it says what is missing and can download RPCS3 for it.
  4. Press Build: the launcher builds the game's code on your PC, once for each version, in about five to ten minutes.
  5. Pick a preset and press Play.

FAQ

Is there an official PC version of God of War: Ascension?

No. God of War: Ascension came out on PlayStation 3 only. Ascension-R is an unofficial fan project, not affiliated with or endorsed by Sony.

How is Ascension-R different from playing on RPCS3?

RPCS3 emulates the PS3 and runs the game's code as it goes. Ascension-R translates the game's code to native x86-64 code ahead of time, on your PC, and draws with Direct3D 12, so no emulator runs while you play. RPCS3 is used only to decrypt your copy.

Do I need to own God of War: Ascension?

Yes. The download holds no code or assets of the game. Its launcher builds the game's code from your own copy, with its license.

Which copies of the game work?

Only the digital US release NPUA80918 at version 1.12, with every update from 1.04 installed in RPCS3. European and disc releases are not supported yet.

Does it run on Linux or the Steam Deck?

One player plays it on Linux through Proton, in a Wine prefix made by Lutris. The Steam Deck has not been tried.

Is it safe to run?

The code is open source under the MIT License and built in the open. Each release lists the SHA-256 of its download and what the package was checked for. The game's code is built on your own PC. The program is not signed, so Windows SmartScreen may warn the first time.

Where do I report a problem?

Report a problem, in the launcher, makes a zip of the logs to attach to an issue on GitHub.
